### CLAVE DE LA API DE AEMET
Para adquirir una clave de la API de Aemet, es necesario ir al link https://opendata.aemet.es/centrodedescargas/inicio y solicitar una clave en el botón de obtención de API Key. Tras eso, se debe escribir un correo electrónico y seguir los pasos que indica el propio correo electrónico que llegará a la bandeja de entrada del correo escrito.
